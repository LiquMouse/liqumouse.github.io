VScode连接到WSL2报错1006

问题的发生

使用VScode连接到WSL2时持续出现 Error: WebSocket close with status code 1006，反复重试均失败。

排查过程

首先检查 WSL2 本身

WSL2 运行正常，不是 WSL 本身的问题。

检查 VScode Server

在 WSL2 内查看日志:

Server 启动正常，日志显示 “Extension host agent started”，没有崩溃。说明问题不在 Server 端，而在连接通道上。

教训

  • 不要轻易给全局工具设置兼容模式。 这个 WIN8RTM 可能是为了某个旧软件设置的，但被 Windows 匹配到了 VScode 上。
  • 看到 __COMPAT_LAYER 环境变量时立刻警觉。 这个变量会系统性地影响所有子进程的 Windows API 返回值。
  • WebSocket 1006 只是症状，不是根因。 1006 = 连接被异常关闭，可能的原因从网络层到应用层都有。关键是在 debug 日志中找到链路上真正断裂的那一环。
